## 🎯 Project Overview

This project is a **tutorial-based water tank design** built in **SOLIDWORKS** to practice and demonstrate fundamental mechanical CAD skills. The tank is constructed using a combination of **sheet metal features**, **extruded geometry**, **revolved profiles**, and **structural weldments** — reflecting real-world fabrication methods.

&gt; 🎓 *Based on the tutorial: [Water Tank Design in SolidWorks](https://www.youtube.com/watch?v=R-KH6XOQz6g) by CAD CAM Tutorial by MahtabAlam*

---

## 🔧 Features Practiced

| # | SOLIDWORKS Feature | Application in This Project |
|---|-------------------|----------------------------|
| 1 | **Base Flange / Tab** *(Sheet Metal)* | Tank shell formed from sheet metal with proper K-factor |
| 2 | **Extruded Boss / Base** | Solid features like mounting plates and flanges |
| 3 | **Extruded Cut** | Holes, openings, and relief cuts |
| 4 | **Reference Planes** | Custom planes for angled features and off-origin sketches |
| 5 | **Mirror** | Symmetric features to reduce modeling time |
| 6 | **Revolved Boss / Base** | Cylindrical or dome-shaped components |
| 7 | **3D Sketch** | Complex paths for structural members |
| 8 | **Structural Member** *(Weldments)* | Support frame using standard steel profiles |
| 9 | **Appearance / Materials** | Realistic material assignments for visualization |

## 🏗️ Design Breakdown

### Tank Body
- **Sheet metal shell** created with `Base Flange` for fabrication-ready flat pattern
- Uniform wall thickness with bend allowances

### Base & Mounting
- **Extruded base plate** with mounting holes (patterned/mirrored)
- Structural support for tank load

### Lid / Top Cover
- **Revolved or extruded profile** with flange for sealing
- Cutouts for inlet/outlet if applicable

### Support Frame
- **3D sketch** defining frame geometry
- **Weldment structural members** (e.g., square/rectangular tubing)
- Trimmed joints and gusset plates for stability

## 💡 What I Learned

- **Sheet Metal Workflow**: How to design with manufacturing in mind — flat patterns, bend radii, and K-factors
- **Weldment Design**: Creating structural frames from standard profiles using 3D sketches
- **Design Intent**: Using mirrors and patterns to build parametric, editable models
- **Multi-Feature Integration**: Combining sheet metal, solids, and weldments in one assembly
- **Visualization**: Applying realistic appearances and materials for presentations
